# IAM Access Review Template

## Overview

This project is a sample Identity and Access Management (IAM) access review template designed to demonstrate how user access can be reviewed, validated, remediated, and documented for audit readiness.

The project is built around a fictional healthcare technology environment and focuses on practical IAM governance concepts such as RBAC, least privilege, user lifecycle management, access reviews, offboarding controls, and evidence collection.

## Purpose

The purpose of this project is to show how access governance can be documented in a structured, repeatable way that supports security operations, compliance, and risk reduction.

This project demonstrates:

- User access review documentation
- RBAC validation
- Least privilege review
- Access approval tracking
- Offboarding control support
- Remediation ownership
- Evidence collection
- Audit-ready documentation

## Scenario

A fictional healthcare organization is conducting a quarterly access review for key systems used by clinical, administrative, and IT staff.

The review is intended to confirm that user access remains appropriate based on job role, department, business need, and least-privilege principles.

## Access Review Scope

The sample access review includes:

- Active Directory group access
- Microsoft 365 access
- VPN access
- Shared mailbox access
- Administrative access
- Clinical application access
- SaaS application access

## Review Questions

Each access review should help answer:

- Does the user still need this access?
- Is the access appropriate for the user’s current role?
- Is the access aligned with least privilege?
- Has the manager or system owner approved the access?
- Is remediation needed?
- Was evidence captured for audit readiness?
